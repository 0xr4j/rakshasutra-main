# Dataset status and provenance

No raw field dataset, hardware logs, site survey, RF measurements, battery traces, deployment record, or experimental protocol accompanied the supplied paper in this repository.

Files in `results/` are generated analytical calculations or outputs from the explicitly configured synthetic traffic model. The small cases in `tests/fixtures/overlap_cases.json` are hand-authored synthetic unit-test fixtures used only to verify collision counting. None is observational data.

Do not describe these files as empirical measurements. Field validation requires an approved protocol, consent and privacy review, instrumented devices, and a documented dataset with provenance.
